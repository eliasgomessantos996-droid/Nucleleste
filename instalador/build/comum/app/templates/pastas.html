Pastas

Atalhos para as pastas da rede (laudos, fotos, PDFs). O botão “Abrir” abre a pasta no Explorador de Arquivos deste computador.

Primeira vez neste computador? Para o botão “Abrir” funcionar, é preciso liberá-lo uma única vez em cada computador:
  1. Clique em Configurar este computador e abra o arquivo baixado (confirme “Sim”).
  2. Depois clique em “Abrir” numa pasta e, se o navegador perguntar, marque “Sempre permitir” e confirme.
A configuração só vale para o seu usuário do Windows e só abre pastas (nunca executa arquivos). Se o botão não abrir nada, use “Copiar caminho” e cole no Explorador.
