# Nucleleste
Sistema de recepção, financeiro, administrativo e atendimento da Clínica de Medicina Nuclear do Leste de Minas Gerais, app criado para otimizar os serviços da recepção utilizando sistemas de agenda que automatizam atendimentos, que automatizam o serviço de atendimento da enfermagem, e assim segue o fluxo de funcionamento da Clínica.
